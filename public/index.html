OverTex.ai

Overleaf, from the chat.

An MCP skill and server. Claude or any MCP client pulls the project, edits the LaTeX, checks refs, and pushes back. You stop copying sections between tabs.

GitHub Hosted MCP

Install

claude mcp add overtex \
  -e OVERLEAF_GIT_TOKEN=olp_your_token \
  -e OVERLEAF_PROJECT_ID=your_project_id \
  -- npx -y github:pruthvirajg/overtex

Token: Overleaf → Menu → Git. That bridge is on paid plans. The skill refuses to push unless you confirm.

What the agent can call

ToolJob
overtex_whoamiSee if git and a TeX compiler are available
overleaf_pullClone or pull the official Git bridge
overleaf_read / writeEdit files in the checkout
latex_check_refsDangling refs, unused labels, missing cites
latex_compilelatexmk, pdflatex, or tectonic if installed
overleaf_pushCommit and push, only with confirm=true

Use OverTex. Pull the project, fix dangling refs in results.tex, compile, and show me the diff before you push.
